# Product Design Series

Five commerce concepts from my UX Lab — each one designed end to end in Figma as a working prototype, each with its own buying process and its own motion-design system. The rule for the whole series: motion stays inside each screen, in its own frame, and explains the product. No gimmicks that travel between screens.

All five are live in the Product Design section of [nithinnamani.com](https://nithinnamani.com).
