# Nike — Commerce UX Concept (Not affiliated with Nike)

Slot 1 of the Product Design series, and the reference the other four were built to match.

**The flow:** Home → Login → Verification → Departments → Browse → Product (inline size selector) → Bag → Checkout → Confirmed. The product you tap is the product you get — the same shoe, photo, and price carries through detail, bag, and payment. Nike Free RN Flyknit, $130; checkout total **$140.73**; order **NK-2026-1042**.

**Motion:** the V3 "Motion" system. The hero carries launch-style energy; the rest of the flow uses motion to explain — every piece plays inside its own screen, in its own frame.

**Figma:** [Nike Commerce UX Redesign — Concept](https://www.figma.com/design/smZ9RC5wl09dr5hHAX1nXj) — desktop + mobile flows, fully prototyped.

Branding stays subtle on purpose — no giant logos splashed across screens. It should feel like shopping, not like an ad for the swoosh. Zero Figma AI used.
